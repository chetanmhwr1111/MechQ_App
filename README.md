# ⚙️ MechQ **MechQ** is a **completely free, locally hosted Streamlit web application** that lets you take comprehensive Mechanical Engineering quizzes directly in your browser at your own convenience. 

 ### 🚀 Key Features 
 * **⏱️ Dual Testing Modes:** Toggle between a pressurized timer mode or a relaxed, untimed self-paced mode. 
 * **📚 Customizable Subject Mix:** Focus intensely on a single topic or generate a comprehensive exam with mixed subjects.
 * **💻 100% Local & Private:** Runs entirely on your browser via a local Streamlit server—no external data tracking, no internet dependency required.
 * **🆓 Completely Free:** Zero paywalls, zero ads, just clean engineering practice.
